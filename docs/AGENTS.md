# Documentation work

The root [AGENTS.md](../AGENTS.md) indexes the repository instruction sets.
Read the [shared workflow](for-agents/workflow.md) and the guides for the current
mode. Those rules also apply when documentation is written in source headers.

For authorized documentation auditing or maintenance:

1. Follow [Documentation workflow](for-agents/documentation.md) for ownership,
   evidence, writing, usefulness review and maintenance policy.
2. Also read [API documentation](for-agents/api-documentation.md) for source
   comments and [Documentation generation](for-agents/documentation-building.md)
   when generating or inspecting the site.
3. Read the affected subject's canonical guide and source owner; follow links
   that answer a question needed for this task.

The [documentation index](README.md) maps published and repository-only material.
The [published hierarchy](site/index.md) owns site navigation. The
[tooling guide](site/development/documentation.md) owns generation commands and
output/cache behavior. For changes to the instruction sets themselves, also use
[Agent instruction library](for-agents/README.md#maintain-this-library).
